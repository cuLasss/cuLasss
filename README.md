## Sobre mim

Gosto de transformar problema solto em sistema funcionando: entender o fluxo, desenhar a solução, automatizar o que é repetitivo e deixar algo útil rodando para pessoas reais.

Hoje meu foco está em **redes**, **cibersegurança**, **OSINT**, **automação de processos** e **criação de sistemas web/mobile**. Também venho estudando pentest e bug bounty de forma responsável, sempre com escopo autorizado, documentação limpa e prova de impacto bem feita.

Uso IA como apoio para acelerar protótipos, revisar decisões e tirar ideias do papel, mas o que me interessa de verdade é o ciclo completo: arquitetura, código, validação, segurança e entrega.

## Projetos que melhor me representam

### [Sentinela IF / Cameras-IF](https://github.com/cuLasss/Cameras-IF)

Sistema de videomonitoramento institucional que reaproveita celulares como câmeras IP, com transmissão ao vivo via WebRTC, acesso remoto seguro por Tailscale/WireGuard e infraestrutura containerizada.

**Por que destaca meu perfil:** mistura redes, segurança, streaming em tempo real, Docker, backend, frontend e uma preocupação forte com exposição mínima na internet.

**Stack:** React, Vite, FastAPI, PostgreSQL, Redis, Docker Compose, MediaMTX, Nginx, Tailscale e WebRTC.

### [Deliver-Bot](https://github.com/cuLasss/Deliver-Bot)

Sistema de automação operacional para WhatsApp, criado para organizar pré-entregas, processar PDFs, gerenciar filiais, controlar bots conectados e reduzir trabalho manual em rotina real de empresa.

**Por que destaca meu perfil:** mostra automação aplicada, integração entre sistemas, painel web, regras de negócio e uma solução pensada para funcionar no dia a dia.

**Stack:** FastAPI, React, Vite, Node.js, Baileys/WhatsApp, SQLite, Docker e Nginx.

### [Dieta Ideal Cabras](https://github.com/cuLasss/Dieta-Ideal-Cabras)

Aplicativo Flutter premiado na FECIB para apoio ao manejo nutricional de cabras leiteiras, com cálculos, registros, lotes, controle leiteiro e organização de dados no dispositivo.

**Por que destaca meu perfil:** é um projeto de produto completo: problema específico, utilidade prática, app mobile, dados locais e reconhecimento acadêmico.

**Stack:** Flutter, Dart, persistência local e lógica de cálculo nutricional.
