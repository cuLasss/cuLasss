## About Me

Sou movido por projetos que conectam software com problemas concretos. Gosto de entender o contexto, desenhar uma solução simples o bastante para ser mantida e completa o suficiente para funcionar no dia a dia.

Minha base passa por desenvolvimento web, automação de processos, aplicações mobile, Docker, APIs, bancos de dados e integrações com serviços externos. Nos últimos projetos, tenho me aproximado cada vez mais de redes privadas, controle de exposição, segurança de aplicações, OSINT e pesquisa autorizada.

Não me apresento como especialista acabado. Prefiro construir, testar, documentar e evoluir com consistência.
