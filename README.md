- 🔭 Atualmente mais inclinado para **redes**, **cibersegurança**, **OSINT**, **pentest autorizado** e **automação de processos**.
- 🛠️ Também gosto muito de criar **sistemas web/mobile**, painéis internos, bots, integrações e ferramentas úteis para rotina real.
